## About Me

<img align="right" width="34%" src="https://media1.giphy.com/media/v1.Y2lkPTc5MGI3NjExbmt3azRuNWo5cWJ5eWJrMW1zaWR4OWYyZ3FoaHQyc2NmdTk4aGtsaCZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/13mfssn73An6De/giphy.gif" alt="" />

I'm Johan — a **Backend Developer & Tech Lead** from Colombia. I build Node.js and .NET Core backends with clean architecture, DDD and a strong bias toward automation.

Right now I'm running three arcs at once: a full-time backend role, teaching the next generation of Node.js developers, and building my own AI-powered SaaS while launching a freelance career.

- 🧩 Focused on **clean architecture, DDD and testable backends**
- ☁️ Working daily with **Azure, Docker and Kubernetes**
- 🤖 Building an **AI-powered document analysis SaaS**
- 🎓 Teaching **Node.js & Azure fundamentals**
- 💬 Ask me about **APIs, backend design or cloud deployments**
